# حصتي — PWA

تطبيق ويب (PWA) لإدارة الصفوف/المجموعات، الطلاب، الاشتراكات الشهرية، والحضور والغياب.
يعمل على الموبايل والتابلت والكمبيوتر من نفس الرابط، وقابل للتثبيت كأيقونة على الشاشة الرئيسية.

## الهوية البصرية
- الاسم: **حصتي**
- اللوجو: أيقونة "كشف حضور + علامة صح" باللون الأزرق، موجودة في `public/icons/` بكل المقاسات المطلوبة (32, 192, 512) بالإضافة إلى `public/favicon.ico`
- لو حابب تغيّر اللوجو بتصميم خاص بيك: استبدل نفس الملفات (`icon-32.png`, `icon-192.png`, `icon-512.png`, `logo-header.png`, `favicon.ico`) بنفس الأسماء ونفس المقاسات، ومفيش أي تعديل تاني مطلوب في الكود

## لماذا PWA + Supabase؟
- **Supabase** قاعدة بيانات سحابية حقيقية (Postgres) — البيانات محفوظة بشكل دائم، مش في كاش المتصفح. حتى لو مسحت بيانات المتصفح أو غيّرت الجهاز، بياناتك موجودة.
- التطبيق يفتح فوراً من أي متصفح، وممكن "تثبيته" على الموبايل/الكمبيوتر ليعمل زي تطبيق عادي (أيقونة + شاشة كاملة بدون شريط المتصفح).
- **ملاحظة مهمة:** لازم اتصال إنترنت لحفظ أي تعديل جديد (إضافة طالب، تسجيل حضور، تسجيل دفعة) لأن البيانات بتتخزن مباشرة على السحابة فوراً — ده هو اللي بيضمن عدم ضياعها. بدون إنترنت تقدر تشوف آخر بيانات اتحمّلت، لكن مش تحفظ تعديلات جديدة.

## الخطوة 1: إنشاء مشروع Supabase (قاعدة البيانات)

1. روح على [supabase.com](https://supabase.com) واعمل حساب مجاني
2. اضغط "New Project"، اختار اسم وكلمة مرور لقاعدة البيانات (احفظها في مكان آمن)
3. بعد ما المشروع يتجهز (دقيقة أو اتنين)، روح لـ **SQL Editor** من القائمة الجانبية
4. افتح ملف `supabase/schema.sql` الموجود في هذا المشروع، انسخ محتواه كامل، الصقه في SQL Editor، واضغط **Run**
   - ده هينشئ كل الجداول المطلوبة (الصفوف، المجموعات، الطلاب، الاشتراكات، الحضور) ويؤمّنها بحيث محدش غيرك يقدر يوصلها
   - **لو كنت شغّلت `schema.sql` من قبل في مشروع Supabase حالي** (يعني مش أول مرة)، شغّل بالترتيب:
     - `supabase/migrations/002_group_schedule.sql` (مواعيد المجموعات)
     - `supabase/migrations/003_payment_transactions.sql` (سجل التحصيل اليومي)
     - `supabase/migrations/004_multi_teacher.sql` (عزل بيانات كل مدرس — **لازم** قبل ما توزّع التطبيق على مدرسين تانيين؛ فيه تعليمات داخل الملف تحتاج منك تحط الـ UID بتاعك الأول)
     - `supabase/migrations/005_assistants.sql` (نظام المساعدين والصلاحيات — **لازم** قبل ما تستخدم شاشة "إدارة المساعدين")
     - `supabase/migrations/006_activity_log.sql` (سجل النشاط — **لازم** قبل ما تستخدم شاشة "سجل النشاط")
     - `supabase/migrations/007_teacher_profile.sql` (اسم المدرس واسم المادة في الهيدر)
     - `supabase/migrations/008_expenses.sql` (المصروفات وصافي الأرباح)
     - `supabase/migrations/009_student_profile_parent_view.sql` (الملف الإلكتروني الشامل للطالب + رابط متابعة ولي الأمر العام)
5. روح لـ **Authentication -> Users** واضغط **Add user** — دي هتبقى بيانات دخولك أنت (المعلّم) للتطبيق. حط بريدك الإلكتروني وكلمة مرور
6. روح لـ **Project Settings -> API**، وسجّل عندك قيمتين:
   - **Project URL**
   - **anon public key**

## الخطوة 2: رفع الكود على GitHub

1. اعمل حساب على [github.com](https://github.com) لو معندكش
2. اعمل **New repository** باسم مثلاً `school-pwa` (Private لو حابب)
3. فك ضغط ملف الكود اللي معاك، وارفعه:
   ```bash
   cd school-pwa
   git init
   git add .
   git commit -m "أول رفع"
   git branch -M main
   git remote add origin https://github.com/USERNAME/school-pwa.git
   git push -u origin main
   ```
   (غيّر `USERNAME` باسم حسابك)

## الخطوة 3: النشر على Vercel

1. روح على [vercel.com](https://vercel.com) وسجّل دخول بحساب GitHub بتاعك
2. اضغط **Add New -> Project**، واختار الـ repository اللي رفعته
3. قبل الضغط على Deploy، افتح قسم **Environment Variables** وضيف المتغيرات:
   - `NEXT_PUBLIC_SUPABASE_URL` = القيمة اللي سجلتها من Supabase
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = القيمة التانية
   - `SUPABASE_SERVICE_ROLE_KEY` = من Supabase -> Project Settings -> API -> **service_role secret key** (⚠️ مفتاح حساس جداً بصلاحيات كاملة — متحطهوش في أي مكان تاني غير هنا، ومتشاركهوش مع حد)
   - `NEXT_PUBLIC_SITE_URL` = رابط تطبيقك بعد النشر (هتعرفه بعد الخطوة 5 تحت — تقدر تضيفه دلوقتي بقيمة مبدئية وترجع تظبطه بعدين، المهم تحدده قبل ما تطبع أي كارت طالب فيه QR)
4. اضغط **Deploy** وانتظر دقيقة أو اتنين
5. هتاخد رابط زي `school-pwa.vercel.app` — ده رابط تطبيقك الدائم، افتحه وسجّل دخول بالبريد وكلمة المرور اللي عملتهم في الخطوة 1-5

**أي تحديث تعمله بعد كده:** فقط `git push` تاني، وVercel هينشر التحديث تلقائياً خلال دقايق.

## الخطوة 4: تثبيت التطبيق كـ PWA

- **على الموبايل (Android/Chrome):** افتح الرابط، هيظهر إشعار "إضافة للشاشة الرئيسية" أو من قائمة المتصفح (⋮) اختار "Install app"
- **على الآيفون (Safari):** افتح الرابط، اضغط زر المشاركة (Share)، ثم "Add to Home Screen"
- **على الكمبيوتر (Chrome/Edge):** هيظهر أيقونة تثبيت (⊕) في شريط العنوان، اضغط عليها

بعد التثبيت، التطبيق هيفتح بأيقونة خاصة وشاشة كاملة زي أي تطبيق عادي.

## آخر تحديث — تطوير الواجهة والتجربة (UI/UX)
- **الوضع الليلي (Dark Mode)**: زر تبديل 🌙/☀️ في الهيدر، يحفظ اختيارك في المتصفح
- **Skeleton loading**: كروت هيكلية متحركة بدل نص "جارِ التحميل..." في كل القوائم
- **Empty states**: رسالة وأيقونة واضحة بدل النص الرمادي العادي لما تكون القائمة فاضية
- **إعادة تنظيم الشاشات**:
  - إحصائيات الشهر (دافع/جزئي/لم يدفع) وزر تصدير التحصيل انتقلوا لشاشة **الحسابات**
  - زر تصدير الحضور انتقل لشاشة **الحضور** نفسها (بيصدّر بيانات اليوم المختار)
  - الشاشة الرئيسية بقت مخصصة لتاريخ اليوم بخط كبير + مجموعات اليوم بس
- **جرد الخزينة اليومي**: كارت جديد في شاشة الحسابات اسمه "المحصّل اليوم" — بيعرض كل عملية تحصيل حصلت النهاردة باسم الطالب والوقت والمبلغ، ومجموعها الكلي. ده محتاج جدول جديد (`payment_transactions`) — شغّل `supabase/migrations/003_payment_transactions.sql` لو مشروعك موجود بالفعل
- **رقم الطالب أصبح تلقائي**: عند اختيار المجموعة في شاشة إضافة طالب، رقم الطالب بيتحسب تلقائياً (تسلسلي داخل نفس المجموعة) ومينفعش تكتبه يدوي
- **عدد طلاب المجموعة**: ظاهر في أعلى شاشة الحضور بمجرد اختيار المجموعة، مع ملخص حاضر/تأخير/غائب
- **إصلاح رابط واتساب**: الأرقام المصرية المحلية (اللي بتبدأ بصفر زي 010xxxxxxxx) بتتحول تلقائياً لصيغة دولية (20xxxxxxxxxx) قبل فتح واتساب، فمفيش رسالة خطأ بعد كده. **ملحوظة:** الكود مضبوط على مصر (كود 20) — لو محتاج كود دولة تاني، غيّره في `lib/whatsapp.js`

## آخر تحديث — بحث موحّد، إشعارات المتأخرات، وتصميم تنقّل جديد
- **بحث موحّد**: أيقونة 🔍 في الهيدر تفتح نافذة بحث سريعة عن أي طالب بالاسم/الرقم/رقم ولي الأمر، وبتوصلك لملفه كامل (اشتراكات + حضور) بضغطة واحدة
- **إشعارات المتأخرات التلقائية**: أول ما تفتح التطبيق كل يوم، لو فيه طلاب عليهم متأخرات الشهر ده هيظهرلك شريط تنبيه أعلى الشاشة "فيه X طالب عليهم متأخرات". وفيه كمان 🔔 في الهيدر تقدر تضغط عليه في أي وقت تشوف نفس المعلومة
- **شاشة الحسابات**: بقت تعرض بس الطلاب اللي لسه عليهم متبقي (لم يدفع / دفع جزء) — أي طالب دفع بالكامل بيختفي من القائمة تلقائياً (الإحصائيات فوق لسه بتوضح العدد الكلي لكل حالة)
- **تصميم جديد للتنقل السفلي**: شريط عائم بحواف دائرية بدل الشريط الملتصق بحافة الشاشة، والشاشة النشطة بقى ليها دائرة ملوّنة حوالين الأيقونة بدل مجرد تغيير اللون

## آخر تحديث — إلغاء الأزرق نهائياً، اندماج الشاشة، خط جديد، ومشاركة ملخص الحصة
- **إلغاء الأزرق بالكامل**: كل الأزرق اتشال من التطبيق (الأزرار، الحدود، التابات، العنصر النشط في التنقل السفلي، تركيز خانات الكتابة) واتستبدل بلوحة رمادي فحمي/Slate موحدة: `#F8FAFC` خلفية فاتحة في الوضع العادي، `#111827` في الوضع الليلي، مع `#1F2937` كلون تفاعلي أساسي
- **اندماج الشاشة (Edge-to-Edge)**: أضفنا `viewport-fit=cover` ولون شريط النظام (status bar) بقى بيتغيّر تلقائي مع الوضع الليلي/النهاري بدل ما يفضل ثابت
- **خط Tajawal**: التطبيق كله بقى بخط Tajawal من Google Fonts بدل خط النظام الافتراضي
- **مشاركة ملخص الحصة**: في شاشة الحضور، بعد ما تختار المجموعة، زرار "📋 إعداد ملخص الحصة" — بيخليك تلتقط/ترفع صورة السبورة، تسجّل ملاحظة صوتية سريعة، وتكتب رسالة نصية، وتشاركهم مباشرة (بدون أي رفع على سحابة — الملفات بتتبعت مباشرة من جهازك) بطريقتين:
  - **إرسال فردي متتالي**: بيوريك أولياء الأمور واحد واحد، وكل ما تضغط "شارك"، هتفتح قائمة مشاركة الجهاز عادي وتختار واتساب وتحدد محادثة ولي الأمر بنفسك، وبعدها تضغط "التالي"
  - **مشاركة جروب المجموعة**: مشاركة واحدة، تختار منها جروب واتساب الخاص بالمجموعة

  **⚠️ حدود مهمة تعرفها:** المتصفح (ولا أي تطبيق ويب) مقدرش يفتح واتساب ويختار محادثة أو جروب معين تلقائياً — ده قيد أمان من المتصفح نفسه ومن واتساب. يعني "الإرسال الفردي المتتالي" مش إرسال تلقائي بالكامل، لكنه بيجهزلك المحتوى (الصورة+الصوت+النص) جاهز ويوجّهك خطوة بخطوة، وانت بس اللي تختار المحادثة الصح في واتساب كل مرة. برضه المشاركة بالملفات (صورة+صوت مع بعض) محتاجة متصفح حديث على الموبايل (Chrome أو Safari محدّث) — لو المتصفح مش داعم، التطبيق هيشاركلك النص بس ويطلب منك ترفق الصورة/الصوت يدوي.

  **صيغة الصوت:** المتصفح بيسجل الصوت أصلاً بصيغة webm، لكن واتساب بيرفضها كملف صوتي. عشان كده التطبيق بيحوّل التسجيل تلقائياً لصيغة WAV قياسية (مدعومة من الجميع) قبل ما يعرض زرار المشاركة — هتلاحظ لحظة "جارِ تجهيز الصوت..." بعد ما توقف التسجيل، ودي طبيعية.


## إصلاحات هذا التحديث
- **رسالة "غير مصرح لك" الخاطفة**: كانت بتظهر أحياناً لحظياً حتى للمدرس نفسه بسبب سباق توقيت بين التحقق من الجلسة والتحقق من الصلاحيات. اتصلحت من الجذر: بيانات صلاحيات المستخدم بقت بتتجاب مرة واحدة بس وتتشارك بين كل الشاشات (بدل ما كل شاشة تجيبها لوحدها كل مرة تتنقل فيها)، وبقت بتعتمد على فحص أسرع وأوثق للجلسة
- **أزرار التعديل والحذف**: بقت أيقونات بدون إطار أو خلفية — قلم ✏️ أصفر للتعديل، وسلة 🗑️ حمراء للحذف — بدل الكلام أو الأزرار المربعة
- **الهيدر على الموبايل**: اسم المدرس واسم المادة بقوا مقصوصين بحرف "..." لو طويلين بدل ما يكسروا التصميم، وشريط الأيقونات بقى مضمون إنه يفضل في سطر واحد أفقي مهما كان حجم الشاشة
- **ترتيب الأيام**: كل مكان في التطبيق (اختيار أيام المجموعة، عرض المواعيد) بقى يبدأ بالسبت وينتهي بالجمعة

## تغيير كلمة المرور واستعادتها
- كل مدرس يقدر يغيّر كلمة المرور بتاعته من داخل التطبيق: أيقونة 👤 في الهيدر → **إعدادات الحساب** → يكتب كلمة المرور الجديدة مرتين ويضغط تحديث
- في شاشة تسجيل الدخول، فيه زرار **"نسيت كلمة المرور؟"** — المدرس يكتب بريده، ويوصله إيميل من Supabase فيه رابط استعادة، وبيفتحله صفحة `/reset-password` يحدد فيها كلمة مرور جديدة

**⚠️ خطوة إعداد لازمة في Supabase عشان رابط الاستعادة يشتغل:**
1. روح لـ Supabase → **Authentication → URL Configuration**
2. في **Site URL** حط رابط موقعك على Vercel (مثلاً `https://your-app.vercel.app`)
3. في **Redirect URLs** ضيف نفس الرابط + `/reset-password` (مثلاً `https://your-app.vercel.app/reset-password`)

من غير الخطوة دي، Supabase مش هيوجّه رابط الإيميل لصفحة الاستعادة الصح.

## إدارة المساعدين (Assistants) والصلاحيات
المدرس (صاحب الحساب) يقدر يضيف حسابات لمساعدين (زي سكرتيرة أو مدرس مساعد) يشتغلوا على نفس بياناته، وكل مساعد يقدر يعمل بس اللي انت مديله صلاحية له.

**إزاي تضيف مساعد:**
1. سجّل دخول بحساب المدرس، روح لـ 👤 إعدادات الحساب → **إدارة المساعدين**
2. املأ اسمه، إيميله، كلمة مرور، وحدد الصلاحيات بالـ checkboxes
3. اضغط "إضافة المساعد" — هيقدر يدخل فوراً بنفس البيانات دي

**الصلاحيات المتاحة:**
- ✅ تسجيل الحضور والغياب
- ✅ تحصيل الاشتراكات والرسوم
- ✅ إضافة وتعديل بيانات الطلاب
- ✅ الاطّلاع على التقارير المالية وإجمالي التحصيل (لو متعطّلة، المساعد ميشوفش إجماليات الشهر ولا سجل "المحصّل اليوم")

المساعد بيشوف بس الشاشات اللي عنده صلاحية ليها (شريط التنقل بيتغيّر تلقائي حسب صلاحياته)، وشاشتي "الصفوف" و"إدارة المساعدين" مقصورتين على المدرس بس مهما كانت الصلاحيات.

**إيقاف أو حذف مساعد:** من نفس الشاشة، تقدر توقف الحساب مؤقتاً (يفقد الدخول فوراً لكن بياناته وسجله فاضلين) أو تحذفه نهائياً (بيتمسح حساب الدخول بتاعه بالكامل).

**⚠️ ملحوظة أمان مهمة تعرفها:** صلاحية "تحصيل الاشتراكات" لازم المساعد يشوف مبلغ كل طالب المستحق والمدفوع عشان يقدر يسجّل الدفعة صح — دي حاجة عملية مينفعش من غيرها. لكن صلاحية "التقارير المالية" منفصلة تماماً وبتتحكم بس في **الإجماليات والتقارير المجمّعة** (زي "إجمالي التحصيل الشهر ده" أو سجل الخزينة اليومي) على مستوى الواجهة. يعني لو مساعد عنده صلاحية التحصيل بس مالوش صلاحية التقارير، هو يقدر يسجّل دفعة طالب معيّن، لكن مش هيشوف "المدرسة عملت كام الشهر ده" كرقم إجمالي. الأمان الأساسي (منع أي حد برّه فريقك من الوصول للبيانات خالص) متطبّق بالكامل جوه قاعدة البيانات نفسها (RLS) ومحصّن ضد أي تلاعب من المتصفح.

## سجل النشاط (متابعة المدرس لأفعال الفريق)
من 👤 إعدادات الحساب → **سجل النشاط** (للمدرس بس)، تقدر تشوف آخر 100 عملية حصلت — مين سجّل حضور مين وامتى، ومين حصّل فلوس من مين وقد إيه، ومين أضاف/عدّل/حذف طالب. مفيد جداً لو عندك أكتر من مساعد بيشتغلوا في نفس الوقت.

## استيراد الطلاب دفعة واحدة
في شاشة الطلاب، زرار **"📥 استيراد"** بيدّيك تفتح قسم ترفع منه ملف CSV فيه قائمة طلاب كاملة بدل ما تضيفهم واحد واحد.

**صيغة الملف** (زي ما هيّجيلك بالظبط لو دُست "تنزيل نموذج فارغ"):
```
الاسم, رقم ولي الأمر, اسم الصف, اسم المجموعة
أحمد محمد, 01012345678, الأول الابتدائي, مجموعة أ
```
- **اسم الصف واسم المجموعة لازم يطابقوا الموجود عندك بالظبط** (بدون حساسية لحالة الأحرف، لكن لازم يكونوا موجودين مسبقاً من شاشة الصفوف) — لو مش متطابقين، الصف ده هيفشل ويظهرلك السبب بعد الاستيراد عشان تصلحه وتعيد المحاولة
- رقم الطالب التلقائي بيتحسب صح حتى لو استوردت أكتر من طالب لنفس المجموعة مرة واحدة
- أي صف نجح استيراده بينضاف فوراً، والصفوف الفاشلة بس محتاجة تصحيح وإعادة رفع

## رسالة ترحيب تلقائية لولي الأمر
لما تضيف طالب جديد وله رقم ولي أمر، بعد الحفظ مباشرة بيظهرلك كارت فيه زرار "إرسال رسالة ترحيب عبر واتساب" برسالة جاهزة فيها اسم الطالب والصف والاشتراك الشهري — تقدر تبعتها فوراً أو تتجاهلها.

## اتجاه التحصيل (رسم بياني)
في شاشة الحسابات (لو عندك صلاحية التقارير المالية)، كارت جديد بيوريك إجمالي التحصيل لآخر 6 شهور كرسم بياني بسيط، عشان تلاحظ بصرياً هل التحصيل بيزيد ولا بينقص.

## ملخص سريع لكل مجموعة
في شاشة الصفوف، تحت اسم كل مجموعة هتلاقي: عدد الطلاب، نسبة الحضور للشهر الحالي، وعدد الدافعين من إجمالي الطلاب — كل ده من غير ما تدخل شاشة تانية.

## تصدير PDF / طباعة
زرار **"طباعة / PDF"** في شاشتي الحسابات والحضور — بيفتح نافذة طباعة من المتصفح نفسه فيها تقرير منسّق، وتختار منها "حفظ كـ PDF". الطريقة دي متعمّدة بدل مكتبات توليد PDF التقنية، عشان تضمن ظهور العربي صح 100% في كل الحالات من غير أي تعقيد إضافي.

## مجموعات اليوم — كروت تفاعلية
الشاشة الرئيسية بقت تعرض كل مجموعة اليوم كـ"كارت" بدل سطر بسيط: عنوان المجموعة مع شارة "مباشر" (لو الوقت داخل الحصة دلوقتي) أو "قادمة"، وتفاصيل سريعة (عدد الطلاب • الميعاد • عدد اللي لسه مدفعوش)، وشريط تقدّم بصري بيوضح كام فاضل على انتهاء الحصة أو كام باقي على بدايتها — وبيتحدّث تلقائي كل دقيقة من غير ما تعمل تحديث للصفحة.

## الجدول الأسبوعي
شاشة جديدة (رابط "الجدول الأسبوعي ←" فوق كارت "مجموعات اليوم" في الرئيسية) بتعرض كل المجموعات مرتبة على أيام الأسبوع كامل، مش النهاردة بس. الأسبوع بيبدأ بالسبت وينتهي بالجمعة، والعرض بيبدأ دايماً بيوم النهاردة أولاً (متميّز بلون مختلف) وبعدين باقي الأيام بالترتيب — كل مجموعة تقدر تضغط عليها تروح مباشرة لتسجيل حضورها.

## المصروفات وصافي الأرباح
شاشة الحسابات بقى فيها تبويبين: **الاشتراكات** (زي ما هي) و**المصروفات** (جديد). في تبويب المصروفات تقدر تسجّل أي بند مصروف (إيجار، طباعة، رواتب مساعدين...) بمبلغه وتاريخه وملاحظات اختيارية، وتعدّل أو تحذف أي بند بالأيقونات المعتادة.

فوق الشاشة، كروت الإحصائيات بقت تشمل **إجمالي التحصيل**، **إجمالي المصروفات**، و**صافي الربح** (المحصّل ناقص المصروفات) لنفس الشهر المختار — ولونه بيتغيّر أخضر لو موجب وأحمر لو سالب. اختيار الشهر والسنة بيفلتر الاثنين (الاشتراكات والمصروفات) مع بعض.

**⚠️ الصلاحيات**: الوحدة دي بالكامل (عرض وإضافة وتعديل وحذف) مقصورة على المدرس، أو أي مساعد عنده صلاحية "الاطّلاع على التقارير المالية" تحديداً — حتى لو عنده صلاحية "تحصيل الاشتراكات"، لو مفيش عنده صلاحية التقارير المالية مش هيشوف تبويب المصروفات أو كروت صافي الربح خالص.

## تحسينات واجهة إضافية (إصلاح مهم + إعادة تنظيم)
- **إصلاح تداخل النوافذ المنبثقة مع الكيبورد والشريط السفلي**: كل النوافذ المنبثقة (إضافة صف/طالب/مجموعة، رسالة جماعية، متأخرات، البحث، ملخص الحصة) بقت تترسم مباشرة فوق باقي الصفحة بالكامل (عن طريق React Portal) بدل ما تكون جوه شجرة الصفحة، فمفيش احتمال تتغطى بأي عنصر تاني زي الشريط السفلي. كمان أي حقل تدوس عليه بيتحرّك تلقائياً ليفضل ظاهر فوق الكيبورد
- **شاشة الصفوف والمجموعات**: فورم "إضافة مجموعة" بقى نافذة منبثقة منفصلة (زرار "+ إضافة مجموعة" داخل كارت كل صف) بدل فورم ثابت. كل مجموعة بقت في مستطيل فرعي خفيف مميّز، بترتيب: اسم المجموعة، المواعيد تحته بخط أصغر، وشارات إحصائية (عدد الطلاب، نسبة الحضور، الدافعين) في سطر تالت، والأيقونات كلها مجمّعة في صف واحد
- **الرسم البياني**: أسماء الشهور بقت كاملة (مش مقصوصة)، وهامش أعلى/أسفل الكارت زاد عشان مفيش حاجة بتلزق بالحافة، والمبلغ الكامل بقى يظهر في تولتيب صغير لما تدوس أو تمرر على أي نقطة بدل ما يكون مزاحم فوقها طول الوقت

## تطوير شكل الواجهة (تحديث تصميمي)


- **الهيدر**: الأيقونات (بحث، إشعارات، ثيم، حساب، خروج) بقت شفافة تماماً من غير إطارات أو مربعات، واسم المدرس واسم المادة بقوا بخط أوضح وأقوى بصرياً
- **رسم بياني اتجاه التحصيل**: بقى منحني بتدرج لوني (أزرق-بنفسجي) بدل الأعمدة السميكة، بشكل Dashboard أحدث
- **إضافة صف جديد / طالب جديد**: بقت نافذة منبثقة (Slide-up) تفتح من زرار عائم ➕ تحت يمين الشاشة، بدل فورم ثابت ياخد مساحة كبيرة فوق القائمة دايماً
- **كروت المجموعات المباشرة**: بقى ليها إطار متوهّج (Glow) أخضر خفيف يميّزها فوراً وانت وسط الحصص
- **⚠️ شارة المتأخرات بقت تفاعلية**: تدوس عليها في أي كارت مجموعة (سواء كانت مباشرة أو قادمة)، تفتحلك نافذة سريعة فيها كل طالب لسه مدفعش (اسمه، رقم ولي أمره، المبلغ المتبقي بالظبط)، مع زرار **"💰 دفع"** يسجّل السداد فوراً من غير ما تسيب الرئيسية، وزرار **واتساب** لتذكير فوري. الميزة دي متاحة لأي حد عنده صلاحية "تحصيل الاشتراكات" (المدرس أو المساعد المصرّح له)

## رسالة جماعية عبر واتساب
في شاشة الصفوف، زرار 💬 أخضر جنب كل مجموعة (يبعت لطلاب المجموعة دي بس) وجنب كل صف (يبعت لكل طلاب الصف بجميع مجموعاته). بيفتح نافذة تكتب فيها رسالة مرة واحدة، مع **متغيرات ذكية** تقدر تضيفها بضغطة زرار: `{اسم_الطالب}`، `{اسم_المجموعة}`، `{اسم_الصف}` — كل واحدة بتتحول تلقائياً لبيانات كل طالب لما تدوس "بدء الإرسال".

**آلية الإرسال:** بما إن الطريقة مجانية بالكامل (روابط واتساب مباشرة `wa.me`، مفيش أي خدمة إرسال مدفوعة أو API)، المتصفح فنياً مقدرش يبعت رسايل تلقائياً وراء بعض بدون تدخل بشري — فالتطبيق بيوريك كل طالب بالتتابع مع معاينة الرسالة المخصصة له، وزرار واحد "إرسال التالي" بيفتح واتساب بالرسالة جاهزة **وفي نفس اللحظة يتحضّرلك الطالب اللي بعده** — فبمجرد ما ترجع للتطبيق تدوس نفس الزرار تاني على طول من غير خطوات إضافية. فيه كمان زرار "تخطي" لو حبيت تتخطى رقم معيّن، وزرار "رجوع" لو حبيت تعدّل نص الرسالة في النص.

## بيانات المدرّس في الهيدر


من 👤 إعدادات الحساب (للمدرس بس)، فيه كارت "بيانات المدرّس" تكتب فيه اسمك واسم المادة اللي بتدرّسها — بيظهروا بعد كده في أعلى كل شاشات التطبيق (للمدرس ولأي مساعد بيشتغل معاه).

## نسخة احتياطية شاملة
من 👤 إعدادات الحساب (للمدرس بس)، زرار **"💾 نسخة احتياطية شاملة"** بينزّل ملف واحد (JSON) فيه كل بياناتك: الصفوف، المجموعات، الطلاب، الاشتراكات، الحضور، وسجل التحصيل — نسخة احتياطية إضافية براحتك بعيد عن الاعتماد الكلي على Supabase.

## توزيع التطبيق على أكتر من مدرس (كل مدرس يشوف بياناته بس)
التطبيق بقى يدعم أكتر من مدرس على نفس المشروع، وكل مدرس بيشوف الصفوف/الطلاب/الحسابات/الحضور **بتاعته هو بس** — معزولين تماماً عن أي مدرس تاني، عن طريق Row Level Security في قاعدة البيانات. مفيش صفحة تسجيل (Sign up) داخل التطبيق نفسه عن قصد — الحسابات بتتعمل من جانبك انت بس، بالخطوات دي:

1. روح لمشروعك في Supabase -> **Authentication -> Users**
2. اضغط **Add user**
3. حط إيميل وكلمة مرور للمدرس، وتأكد إن خيار **Auto Confirm User** مفعّل (وإلا الحساب هيفضل معلّق ومش هيقدر يدخل)
4. اضغط Create — وسلّم المدرس الإيميل وكلمة المرور دول يدخل بيهم على نفس رابط التطبيق

أول ما المدرس الجديد يسجّل دخول، هيلاقي التطبيق فاضي تماماً (صفوف، طلاب، حسابات) عشان يبدأ يبني بياناته هو من الصفر — من غير ما يشوف حرف واحد من بيانات أي مدرس تاني، ومن غير أي إعداد إضافي مطلوب منك في الكود.

**لو عندك بيانات موجودة بالفعل من قبل التحديث ده:** لازم تشغّل `supabase/migrations/004_multi_teacher.sql` قبل ما تضيف أي مدرس تاني — الملف بيربط كل البيانات الحالية بحسابك انت (كصاحبها الأصلي)، وبعدين يفعّل العزل. فيه تعليمات مكتوبة جوه الملف نفسه.

## آخر تحديث — الملف الإلكتروني الشامل للطالب + متابعة ولي الأمر
- **تبويب الدرجات في شاشة الطالب**: جدول بسيط لرصد درجات الكويزات والواجبات (تاريخ - اسم الدرس - الدرجة من - ملاحظة)، مع إضافة/تعديل/حذف (نفس صلاحية "الطلاب")
- **كارت ملخص مالي وحضور**: أعلى شاشة الطالب — نسبة حضوره الشهر ده، حالة تسديد الاشتراك، ومعدّل درجاته العام
- **صفحة ولي الأمر العامة (`/p/[token]`)**: صفحة للقراءة فقط، من غير تسجيل دخول، مصممة للموبايل، وبتعرض نفس الملخص + سجل الحضور والاشتراكات والدرجات — كل طالب له رابط خاص بيه (توكن عشوائي غير قابل للتخمين) محمي عن باقي الطلاب وبيانات المدرس عبر مسار API مخصص على السيرفر
- **زر "📱 إرسال رابط المتابعة لولي الأمر"**: في شاشة الطالب، بيفتح واتساب برسالة جاهزة فيها رابط المتابعة (ولإضافة لمسة شخصية، اتضاف حقل اختياري "اسم ولي الأمر" في بيانات الطالب يتحط في بداية الرسالة لو موجود)
- **ملاحظة**: لازم تشغّل `supabase/migrations/009_student_profile_parent_view.sql` (لو مشروعك موجود بالفعل) عشان تضيف جدول الدرجات وعمود رابط ولي الأمر

## كود QR بقى بيخدم غرضين في نفس الوقت
- **من غير تغيير في شكل الكارت**: نفس الكارنيه المطبوع، لكن الكود جواه بقى رابط كامل لصفحة متابعة ولي الأمر (`/p/[token]`) بدل نص داخلي
- **ماسح التطبيق (شاشة الحضور)**: لسه بيتعرف على الكود فوراً من الكاش المحلي ويسجّل الحضور زي ما هو بالظبط — ومازال بيتعرف كمان على كروت اتطبعت بالصيغة القديمة قبل التحديث ده
- **كاميرا موبايل عادية (ولي الأمر/الطالب)**: أي مسح للكود بكاميرا الموبايل الطبيعية بيفتح صفحة المتابعة العامة على طول في المتصفح، وفيها الحضور والمدفوعات والدرجات محدثة لحظة بلحظة
- **⚠️ مهم قبل ما تطبع أي كارت طالب**: حدّد `NEXT_PUBLIC_SITE_URL` في متغيرات البيئة (Vercel + `.env.local` محلياً) بدومين التطبيق الرسمي بعد النشر. لو طبعت من غير ما يكون المتغيّر ده متحدد، الرابط جوه الكود هيتحدد حسب الجهاز اللي طبعت منه (ممكن يبقى لوكال هوست مثلاً) والكارت هيبقى غلط. ولو غيّرت الدومين بعدين، الكروت القديمة هتحتاج طباعة تانية

## شاشة رصد الدرجات الجماعي (رصد كويز لمجموعة كاملة في خطوة واحدة)
- شاشة جديدة `/quiz-grading` — متاحة من زرار "📝 رصد درجات جماعي" أعلى شاشة الطلاب، وكمان من زرار "📝 درجات" على كارت كل مجموعة في الرئيسية
- اختار المجموعة + اسم الكويز + الدرجة النهائية، وقائمة طلاب المجموعة بتتحمّل تلقائياً مع خانة درجة وملاحظة لكل طالب
- تنقّل سريع بين خانات الدرجات بـ Enter (بينده مباشرة لخانة الطالب اللي بعده) أو Tab
- **مسح QR للتحديد السريع**: زرار "📷 مسح QR للتحديد السريع" بيفتح الكاميرا جوه نفس الشاشة، ومسح كارت أي طالب من المجموعة بينقل المؤشر لخانة درجته على طول من غير تمرير يدوي
- زرار "حفظ ورصد درجات المجموعة" بيحفظ كل الدرجات المدخلة دفعة واحدة (Bulk Insert)، وبتظهر فوراً في رابط متابعة ولي الأمر بتاع كل طالب (نفس جدول `student_scores` المستخدم في تبويب الدرجات بشاشة الطالب)
كل الاقتراحات اللي اتناقشت لحد دلوقتي اتنفّذت. لو عندك أفكار تانية، قول وهنكمل.
