# حصتي — PWA

تطبيق ويب (PWA) لإدارة الصفوف/المجموعات، الطلاب، الاشتراكات الشهرية، والحضور والغياب.
يعمل على الموبايل والتابلت والكمبيوتر من نفس الرابط، وقابل للتثبيت كأيقونة على الشاشة الرئيسية.

## الهوية البصرية
- الاسم: **حصتي**
- اللوجو: أيقونة "كشف حضور + علامة صح" باللون الأزرق، موجودة في `public/icons/` بكل المقاسات المطلوبة (32, 192, 512) بالإضافة إلى `public/favicon.ico`
- لو حابب تغيّر اللوجو بتصميم خاص بيك: استبدل نفس الملفات (`icon-32.png`, `icon-192.png`, `icon-512.png`, `logo-header.png`, `favicon.ico`) بنفس الأسماء ونفس المقاسات، ومفيش أي تعديل تاني مطلوب في الكود

## لماذا PWA + Supabase؟
- **Supabase** قاعدة بيانات سحابية حقيقية (Postgres) — البيانات محفوظة بشكل دائم، مش في كاش المتصفح. حتى لو مسحت بيانات المتصفح أو غيّرت الجهاز، بياناتك موجودة.
- التطبيق يفتح فوراً من أي متصفح، وممكن "تثبيته" على الموبايل/الكمبيوتر ليعمل زي تطبيق عادي (أيقونة + شاشة كاملة بدون شريط المتصفح).
- **ملاحظة مهمة:** لازم اتصال إنترنت لحفظ أي تعديل جديد (إضافة طالب، تسجيل حضور، تسجيل دفعة) لأن البيانات بتتخزن مباشرة على السحابة فوراً — ده هو اللي بيضمن عدم ضياعها. بدون إنترنت تقدر تشوف آخر بيانات اتحمّلت، لكن مش تحفظ تعديلات جديدة.

## الخطوة 1: إنشاء مشروع Supabase (قاعدة البيانات)

1. روح على [supabase.com](https://supabase.com) واعمل حساب مجاني
2. اضغط "New Project"، اختار اسم وكلمة مرور لقاعدة البيانات (احفظها في مكان آمن)
3. بعد ما المشروع يتجهز (دقيقة أو اتنين)، روح لـ **SQL Editor** من القائمة الجانبية
4. افتح ملف `supabase/schema.sql` الموجود في هذا المشروع، انسخ محتواه كامل، الصقه في SQL Editor، واضغط **Run**
   - ده هينشئ كل الجداول المطلوبة (الصفوف، المجموعات، الطلاب، الاشتراكات، الحضور) ويؤمّنها بحيث محدش غيرك يقدر يوصلها
   - **لو كنت شغّلت `schema.sql` من قبل في مشروع Supabase حالي** (يعني مش أول مرة)، شغّل بالترتيب:
     - `supabase/migrations/002_group_schedule.sql` (مواعيد المجموعات)
     - `supabase/migrations/003_payment_transactions.sql` (سجل التحصيل اليومي)
     - `supabase/migrations/004_multi_teacher.sql` (عزل بيانات كل مدرس — **لازم** قبل ما توزّع التطبيق على مدرسين تانيين؛ فيه تعليمات داخل الملف تحتاج منك تحط الـ UID بتاعك الأول)
5. روح لـ **Authentication -> Users** واضغط **Add user** — دي هتبقى بيانات دخولك أنت (المعلّم) للتطبيق. حط بريدك الإلكتروني وكلمة مرور
6. روح لـ **Project Settings -> API**، وسجّل عندك قيمتين:
   - **Project URL**
   - **anon public key**

## الخطوة 2: رفع الكود على GitHub

1. اعمل حساب على [github.com](https://github.com) لو معندكش
2. اعمل **New repository** باسم مثلاً `school-pwa` (Private لو حابب)
3. فك ضغط ملف الكود اللي معاك، وارفعه:
   ```bash
   cd school-pwa
   git init
   git add .
   git commit -m "أول رفع"
   git branch -M main
   git remote add origin https://github.com/USERNAME/school-pwa.git
   git push -u origin main
   ```
   (غيّر `USERNAME` باسم حسابك)

---

## الخطوة 3: النشر على Vercel

1. روح على [vercel.com](https://vercel.com) وسجّل دخول بحساب GitHub بتاعك
2. اضغط **Add New -> Project**، واختار الـ repository اللي رفعته
3. قبل الضغط على Deploy، افتح قسم **Environment Variables** وضيف المتغيرين:
   - `NEXT_PUBLIC_SUPABASE_URL` = القيمة اللي سجلتها من Supabase
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = القيمة التانية
4. اضغط **Deploy** وانتظر دقيقة أو اتنين
5. هتاخد رابط زي `school-pwa.vercel.app` — ده رابط تطبيقك الدائم، افتحه وسجّل دخول بالبريد وكلمة المرور اللي عملتهم في الخطوة 1-5

**أي تحديث تعمله بعد كده:** فقط `git push` تاني، وVercel هينشر التحديث تلقائياً خلال دقايق.

## الخطوة 4: تثبيت التطبيق كـ PWA

- **على الموبايل (Android/Chrome):** افتح الرابط، هيظهر إشعار "إضافة للشاشة الرئيسية" أو من قائمة المتصفح (⋮) اختار "Install app"
- **على الآيفون (Safari):** افتح الرابط، اضغط زر المشاركة (Share)، ثم "Add to Home Screen"
- **على الكمبيوتر (Chrome/Edge):** هيظهر أيقونة تثبيت (⊕) في شريط العنوان، اضغط عليها

بعد التثبيت، التطبيق هيفتح بأيقونة خاصة وشاشة كاملة زي أي تطبيق عادي.

## آخر تحديث — تطوير الواجهة والتجربة (UI/UX)
- **الوضع الليلي (Dark Mode)**: زر تبديل 🌙/☀️ في الهيدر، يحفظ اختيارك في المتصفح
- **Skeleton loading**: كروت هيكلية متحركة بدل نص "جارِ التحميل..." في كل القوائم
- **Empty states**: رسالة وأيقونة واضحة بدل النص الرمادي العادي لما تكون القائمة فاضية
- **إعادة تنظيم الشاشات**:
  - إحصائيات الشهر (دافع/جزئي/لم يدفع) وزر تصدير التحصيل انتقلوا لشاشة **الحسابات**
  - زر تصدير الحضور انتقل لشاشة **الحضور** نفسها (بيصدّر بيانات اليوم المختار)
  - الشاشة الرئيسية بقت مخصصة لتاريخ اليوم بخط كبير + مجموعات اليوم بس
- **جرد الخزينة اليومي**: كارت جديد في شاشة الحسابات اسمه "المحصّل اليوم" — بيعرض كل عملية تحصيل حصلت النهاردة باسم الطالب والوقت والمبلغ، ومجموعها الكلي. ده محتاج جدول جديد (`payment_transactions`) — شغّل `supabase/migrations/003_payment_transactions.sql` لو مشروعك موجود بالفعل
- **رقم الطالب أصبح تلقائي**: عند اختيار المجموعة في شاشة إضافة طالب، رقم الطالب بيتحسب تلقائياً (تسلسلي داخل نفس المجموعة) ومينفعش تكتبه يدوي
- **عدد طلاب المجموعة**: ظاهر في أعلى شاشة الحضور بمجرد اختيار المجموعة، مع ملخص حاضر/تأخير/غائب
- **إصلاح رابط واتساب**: الأرقام المصرية المحلية (اللي بتبدأ بصفر زي 010xxxxxxxx) بتتحول تلقائياً لصيغة دولية (20xxxxxxxxxx) قبل فتح واتساب، فمفيش رسالة خطأ بعد كده. **ملحوظة:** الكود مضبوط على مصر (كود 20) — لو محتاج كود دولة تاني، غيّره في `lib/whatsapp.js`

## آخر تحديث — بحث موحّد، إشعارات المتأخرات، وتصميم تنقّل جديد
- **بحث موحّد**: أيقونة 🔍 في الهيدر تفتح نافذة بحث سريعة عن أي طالب بالاسم/الرقم/رقم ولي الأمر، وبتوصلك لملفه كامل (اشتراكات + حضور) بضغطة واحدة
- **إشعارات المتأخرات التلقائية**: أول ما تفتح التطبيق كل يوم، لو فيه طلاب عليهم متأخرات الشهر ده هيظهرلك شريط تنبيه أعلى الشاشة "فيه X طالب عليهم متأخرات". وفيه كمان 🔔 في الهيدر تقدر تضغط عليه في أي وقت تشوف نفس المعلومة
- **شاشة الحسابات**: بقت تعرض بس الطلاب اللي لسه عليهم متبقي (لم يدفع / دفع جزء) — أي طالب دفع بالكامل بيختفي من القائمة تلقائياً (الإحصائيات فوق لسه بتوضح العدد الكلي لكل حالة)
- **تصميم جديد للتنقل السفلي**: شريط عائم بحواف دائرية بدل الشريط الملتصق بحافة الشاشة، والشاشة النشطة بقى ليها دائرة ملوّنة حوالين الأيقونة بدل مجرد تغيير اللون

## آخر تحديث — إلغاء الأزرق نهائياً، اندماج الشاشة، خط جديد، ومشاركة ملخص الحصة
- **إلغاء الأزرق بالكامل**: كل الأزرق اتشال من التطبيق (الأزرار، الحدود، التابات، العنصر النشط في التنقل السفلي، تركيز خانات الكتابة) واتستبدل بلوحة رمادي فحمي/Slate موحدة: `#F8FAFC` خلفية فاتحة في الوضع العادي، `#111827` في الوضع الليلي، مع `#1F2937` كلون تفاعلي أساسي
- **اندماج الشاشة (Edge-to-Edge)**: أضفنا `viewport-fit=cover` ولون شريط النظام (status bar) بقى بيتغيّر تلقائي مع الوضع الليلي/النهاري بدل ما يفضل ثابت
- **خط Tajawal**: التطبيق كله بقى بخط Tajawal من Google Fonts بدل خط النظام الافتراضي
- **مشاركة ملخص الحصة**: في شاشة الحضور، بعد ما تختار المجموعة، زرار "📋 إعداد ملخص الحصة" — بيخليك تلتقط/ترفع صورة السبورة، تسجّل ملاحظة صوتية سريعة، وتكتب رسالة نصية، وتشاركهم مباشرة (بدون أي رفع على سحابة — الملفات بتتبعت مباشرة من جهازك) بطريقتين:
  - **إرسال فردي متتالي**: بيوريك أولياء الأمور واحد واحد، وكل ما تضغط "شارك"، هتفتح قائمة مشاركة الجهاز عادي وتختار واتساب وتحدد محادثة ولي الأمر بنفسك، وبعدها تضغط "التالي"
  - **مشاركة جروب المجموعة**: مشاركة واحدة، تختار منها جروب واتساب الخاص بالمجموعة

  **⚠️ حدود مهمة تعرفها:** المتصفح (ولا أي تطبيق ويب) مقدرش يفتح واتساب ويختار محادثة أو جروب معين تلقائياً — ده قيد أمان من المتصفح نفسه ومن واتساب. يعني "الإرسال الفردي المتتالي" مش إرسال تلقائي بالكامل، لكنه بيجهزلك المحتوى (الصورة+الصوت+النص) جاهز ويوجّهك خطوة بخطوة، وانت بس اللي تختار المحادثة الصح في واتساب كل مرة. برضه المشاركة بالملفات (صورة+صوت مع بعض) محتاجة متصفح حديث على الموبايل (Chrome أو Safari محدّث) — لو المتصفح مش داعم، التطبيق هيشاركلك النص بس ويطلب منك ترفق الصورة/الصوت يدوي.

  **صيغة الصوت:** المتصفح بيسجل الصوت أصلاً بصيغة webm، لكن واتساب بيرفضها كملف صوتي. عشان كده التطبيق بيحوّل التسجيل تلقائياً لصيغة WAV قياسية (مدعومة من الجميع) قبل ما يعرض زرار المشاركة — هتلاحظ لحظة "جارِ تجهيز الصوت..." بعد ما توقف التسجيل، ودي طبيعية.


## توزيع التطبيق على أكتر من مدرس (كل مدرس يشوف بياناته بس)
التطبيق بقى يدعم أكتر من مدرس على نفس المشروع، وكل مدرس بيشوف الصفوف/الطلاب/الحسابات/الحضور **بتاعته هو بس** — معزولين تماماً عن أي مدرس تاني، عن طريق Row Level Security في قاعدة البيانات. مفيش صفحة تسجيل (Sign up) داخل التطبيق نفسه عن قصد — الحسابات بتتعمل من جانبك انت بس، بالخطوات دي:

1. روح لمشروعك في Supabase -> **Authentication -> Users**
2. اضغط **Add user**
3. حط إيميل وكلمة مرور للمدرس، وتأكد إن خيار **Auto Confirm User** مفعّل (وإلا الحساب هيفضل معلّق ومش هيقدر يدخل)
4. اضغط Create — وسلّم المدرس الإيميل وكلمة المرور دول يدخل بيهم على نفس رابط التطبيق

أول ما المدرس الجديد يسجّل دخول، هيلاقي التطبيق فاضي تماماً (صفوف، طلاب، حسابات) عشان يبدأ يبني بياناته هو من الصفر — من غير ما يشوف حرف واحد من بيانات أي مدرس تاني، ومن غير أي إعداد إضافي مطلوب منك في الكود.

**لو عندك بيانات موجودة بالفعل من قبل التحديث ده:** لازم تشغّل `supabase/migrations/004_multi_teacher.sql` قبل ما تضيف أي مدرس تاني — الملف بيربط كل البيانات الحالية بحسابك انت (كصاحبها الأصلي)، وبعدين يفعّل العزل. فيه تعليمات مكتوبة جوه الملف نفسه.
