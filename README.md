# سجل المدرسة — PWA

تطبيق ويب (PWA) لإدارة الصفوف/المجموعات، الطلاب، الاشتراكات الشهرية، والحضور والغياب.
يعمل على الموبايل والتابلت والكمبيوتر من نفس الرابط، وقابل للتثبيت كأيقونة على الشاشة الرئيسية.

## لماذا PWA + Supabase؟
- **Supabase** قاعدة بيانات سحابية حقيقية (Postgres) — البيانات محفوظة بشكل دائم، مش في كاش المتصفح. حتى لو مسحت بيانات المتصفح أو غيّرت الجهاز، بياناتك موجودة.
- التطبيق يفتح فوراً من أي متصفح، وممكن "تثبيته" على الموبايل/الكمبيوتر ليعمل زي تطبيق عادي (أيقونة + شاشة كاملة بدون شريط المتصفح).
- **ملاحظة مهمة:** لازم اتصال إنترنت لحفظ أي تعديل جديد (إضافة طالب، تسجيل حضور، تسجيل دفعة) لأن البيانات بتتخزن مباشرة على السحابة فوراً — ده هو اللي بيضمن عدم ضياعها. بدون إنترنت تقدر تشوف آخر بيانات اتحمّلت، لكن مش تحفظ تعديلات جديدة.

## الخطوة 1: إنشاء مشروع Supabase (قاعدة البيانات)

1. روح على [supabase.com](https://supabase.com) واعمل حساب مجاني
2. اضغط "New Project"، اختار اسم وكلمة مرور لقاعدة البيانات (احفظها في مكان آمن)
3. بعد ما المشروع يتجهز (دقيقة أو اتنين)، روح لـ **SQL Editor** من القائمة الجانبية
4. افتح ملف `supabase/schema.sql` الموجود في هذا المشروع، انسخ محتواه كامل، الصقه في SQL Editor، واضغط **Run**
   - ده هينشئ كل الجداول المطلوبة (الصفوف، المجموعات، الطلاب، الاشتراكات، الحضور) ويؤمّنها بحيث محدش غيرك يقدر يوصلها
   - **لو كنت شغّلت `schema.sql` من قبل في مشروع Supabase حالي** (يعني مش أول مرة)، شغّل كمان ملف `supabase/migrations/002_group_schedule.sql` عشان يضيف أعمدة مواعيد المجموعة الجديدة
5. روح لـ **Authentication -> Users** واضغط **Add user** — دي هتبقى بيانات دخولك أنت (المعلّم) للتطبيق. حط بريدك الإلكتروني وكلمة مرور
6. روح لـ **Project Settings -> API**، وسجّل عندك قيمتين:
   - **Project URL**
   - **anon public key**

## الخطوة 2: رفع الكود على GitHub

1. اعمل حساب على [github.com](https://github.com) لو معندكش
2. اعمل **New repository** باسم مثلاً `school-pwa` (Private لو حابب)
3. فك ضغط ملف الكود اللي معاك، وارفعه:
   ```bash
   cd school-pwa
   git init
   git add .
   git commit -m "أول رفع"
   git branch -M main
   git remote add origin https://github.com/USERNAME/school-pwa.git
   git push -u origin main
   ```
   (غيّر `USERNAME` باسم حسابك)

---

## الخطوة 3: النشر على Vercel

1. روح على [vercel.com](https://vercel.com) وسجّل دخول بحساب GitHub بتاعك
2. اضغط **Add New -> Project**، واختار الـ repository اللي رفعته
3. قبل الضغط على Deploy، افتح قسم **Environment Variables** وضيف المتغيرين:
   - `NEXT_PUBLIC_SUPABASE_URL` = القيمة اللي سجلتها من Supabase
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = القيمة التانية
4. اضغط **Deploy** وانتظر دقيقة أو اتنين
5. هتاخد رابط زي `school-pwa.vercel.app` — ده رابط تطبيقك الدائم، افتحه وسجّل دخول بالبريد وكلمة المرور اللي عملتهم في الخطوة 1-5

**أي تحديث تعمله بعد كده:** فقط `git push` تاني، وVercel هينشر التحديث تلقائياً خلال دقايق.

---

## الخطوة 4: تثبيت التطبيق كـ PWA

- **على الموبايل (Android/Chrome):** افتح الرابط، هيظهر إشعار "إضافة للشاشة الرئيسية" أو من قائمة المتصفح (⋮) اختار "Install app"
- **على الآيفون (Safari):** افتح الرابط، اضغط زر المشاركة (Share)، ثم "Add to Home Screen"
- **على الكمبيوتر (Chrome/Edge):** هيظهر أيقونة تثبيت (⊕) في شريط العنوان، اضغط عليها

بعد التثبيت، التطبيق هيفتح بأيقونة خاصة وشاشة كاملة زي أي تطبيق عادي.

## هيكل المشروع
```
app/
  login/            صفحة تسجيل الدخول
  (app)/            الشاشات بعد تسجيل الدخول (محمية)
    dashboard/       الرئيسية + التصدير
    grades/          الصفوف والمجموعات
    students/         الطلاب (+ [id] لملف كل طالب)
    accounts/         الاشتراكات الشهرية
    attendance/       الحضور والغياب
lib/
  supabaseClient.js  الاتصال بقاعدة البيانات
  whatsapp.js        بناء روابط واتساب
  exportCsv.js        تصدير CSV (يفتح في Excel)
  constants.js         أسماء الشهور وألوان الحالات
public/
  manifest.json       إعدادات PWA
  sw.js               service worker (يخزّن واجهة التطبيق للعمل أوفلاين)
supabase/
  schema.sql          الجداول + الحماية (RLS)
```

## المستخدم الوحيد المسموح له بالدخول
النظام مبني لمستخدم واحد (المعلّم). لو حبيت تضيف مستخدم تاني (مساعد مثلاً)، ارجع لـ Supabase -> Authentication -> Users -> Add user، وهيقدر يدخل بنفس بيانات الدخول اللي هتديله.
